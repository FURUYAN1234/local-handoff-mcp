# 夕焼け便 / Sunset Delivery

Web版Museの企画をもとにした架空の科学4コマです。NASAとNOAAの公開資料を参照しています。

1. **注文** — 昼の街で、子どもが見習い配達員に「昼は青いのに、どうして夕方は赤いの？」と聞く。
2. **荷物** — 配達員が虹色の荷札を並べ、「太陽の光にはいろいろな色が混ざっているよ」と答える。
3. **遠回り** — 低い太陽と観察者を結ぶ長い道に、青い荷札だけ多く横にそれる矢印を描く。「夕方は大気を長く通って、青い光がいろんな方向に散るんだ」
4. **配達完了** — 赤とオレンジの荷札が夕暮れの街に届く。子どもが雲を見上げて「だから雲も夕焼け色なんだね」と気づく。

作画時は、横にそれる矢印で散乱を示します。荷物は説明のための比喩です。
